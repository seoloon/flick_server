# FlickDD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the FlickDD module: authenticated, throttled, resumable direct-streaming downloads of Jellyfin/Plex media for offline viewing, with analytics, a panel page and a client integration guide.

**Architecture:** FlickDD is a streaming proxy. `POST /api/v1/downloads` (Flick JWT) resolves the item on the backend and issues an in-memory *grant* with an opaque token. `GET /api/v1/downloads/{id}/file` (grant token, `Range`) opens a ranged request upstream and a per-segment *pump task* copies bytes through a per-grant token bucket into a small bounded channel that backs the response body: no disk, no buffer beyond a few 64 KiB chunks. Grants track slots, byte coverage and analytics; the admin API exposes them to a new panel page.

**Tech Stack:** Rust 2024 (axum 0.8, tokio, reqwest streaming, sha2), Next.js panel (TypeScript, no new deps), Markdown docs.

**Spec:** `docs/superpowers/specs/2026-10-03-flickdd-design.md`

## Global Constraints

- At most **10 parallel downloads per user** (`FLICKDD_MAX_PARALLEL=10`), global cap `FLICKDD_MAX_GLOBAL=100`.
- At most **10 MB/s per download** (`FLICKDD_RATE_MBPS=10` = 10 485 760 B/s), bucket shared per grant, burst 256 KiB.
- **No temp file, no full-file buffer**: upstream stream to throttle to channel (capacity 4 chunks of <= 64 KiB) to response body.
- Sources: Jellyfin and Plex, credentials server-side only (`FLICKDD_JELLYFIN_URL/_API_KEY`, `FLICKDD_PLEX_URL/_TOKEN`); redirects not followed; `item_id` matches `^[A-Za-z0-9_-]{1,64}$`.
- Permission `downloads:create` (`PERM_DOWNLOAD`); `*` covers it.
- Download token: 256-bit random, base64url, stored as SHA-256, constant-time compare, never logged (scrub `?token=`).
- Range: single range only; no `Range` header gives 200 full file (not truncated); a `Range` request is answered 206 truncated to `FLICKDD_MAX_RANGE_MB` (64 MiB); multi-range gives 416; `If-Range` with a different ETag gives 200 full.
- Guard rails defaults: grant idle TTL 21600 s, max age 86400 s, stall timeout 30 s, upstream timeout 15 s, upstream retries 2 (250 ms then 1 s backoff), 120 requests/min/grant, over-serve cap 2 x size, advertised chunk 8 MiB.
- Disabled by default: `FLICKDD_ENABLED=false` makes every FlickDD route (client and admin) answer 404 and allocates nothing.
- Outcomes are `completed`, `cancelled`, `expired`, `source_changed`. (`failed` from the spec is dropped: an upstream failure is never terminal, the grant stays resumable and is counted in `flickdd_upstream_errors_total`.)
- Code style: match the crate (pure units take time as an input, `thiserror`, `tracing`, config through `from_lookup`). Gates before every commit: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`. Panel: `npm run typecheck && npm test` in `panel/`.
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

- A client that disconnects and retries immediately while the old TCP connection is still half open: the new request must preempt, not get 409 (Task 4 and 7 tests).
- Resuming with overlapping ranges must not double-count coverage or complete a grant early (Task 3 test).
- Source file replaced on the backend between fragments: 409 `SOURCE_CHANGED`, never silently mixed bytes (Task 6 and 7 tests).
- Client that stops reading (full TCP window): the segment must end after the stall timeout and release the upstream connection (Task 5 test).
- Hostile `item_id`, `Range` and `token` inputs (`../x`, `bytes=5-1`, `bytes=0-1,5-6`, empty token, token of another grant): rejected with the right status, no panic (Tasks 3, 7 tests).

```rust
//! Token bucket with debt, driven by an explicit microsecond timestamp (pure, testable).

pub type Micros = u64;

#[derive(Debug, Clone)]
pub struct Throttle {
    per_us: f64,
    burst: f64,
    tokens: f64,
    last: Micros,
}

impl Throttle {
    pub fn new(rate_bps: u64, burst_bytes: u64, now: Micros) -> Self {
        Self {
            per_us: rate_bps as f64 / 1e6,
            burst: burst_bytes as f64,
            tokens: burst_bytes as f64,
            last: now,
        }
    }

    /// Reserve `bytes`; returns how long the caller must wait before sending them.
    pub fn take(&mut self, bytes: u64, now: Micros) -> Micros {
        let elapsed = now.saturating_sub(self.last) as f64;
        self.last = self.last.max(now);
        self.tokens = (self.tokens + elapsed * self.per_us).min(self.burst);
        self.tokens -= bytes as f64;
        if self.tokens >= 0.0 {
            0
        } else {
            (-self.tokens / self.per_us).ceil() as Micros
        }
    }
}
```

### Task 3: Ranges and coverage (pure)

**Files:** Create `src/dd/ranges.rs`; Modify `src/dd/mod.rs` (`pub mod ranges;`)

**Interfaces:**
- Produces:
  - `pub enum RangeError { Unsatisfiable, Multi }`
  - `pub fn resolve(header: Option<&str>, size: u64, max_len: u64) -> Result<Resolved, RangeError>` where `pub struct Resolved { pub start: u64, pub end: u64 /* inclusive */, pub partial: bool }`. No header: whole file, `partial=false`, not truncated. Header present: `partial=true`, length capped at `max_len`. Syntactically invalid header (unknown unit, garbage): treated as absent (RFC 9110). Multi-range (`,`) gives `Multi`. `start >= size` or `bytes=5-1` gives `Unsatisfiable`. Suffix `bytes=-N` is the last N bytes (N=0 unsatisfiable). End beyond size is clamped.
  - `pub struct Coverage` with `new()`, `add(&mut self, start: u64, end_excl: u64) -> bool` (false when ignored because 512 disjoint ranges already exist), `covered(&self) -> u64`, `is_complete(&self, size: u64) -> bool`.

```rust
const PIECE: usize = 64 * 1024;
const FLUSH: u64 = 1024 * 1024;

async fn run(p: PumpParams, tx: mpsc::Sender<io::Result<Bytes>>) {
    let _guard = EndGuard::new(p.dd.clone(), &p.grant_id, p.segment.epoch); // calls grants.end_segment on drop
    let mut cancel = p.segment.cancel.clone();
    let mut offset = p.start;
    let mut flushed_from = p.start;
    let mut retries = p.dd.cfg.upstream_retries;
    let mut upstream = p.first.bytes_stream();
    'outer: while offset <= p.end {
        let next = tokio::select! {
            biased;
            _ = cancel.changed() => break 'outer,           // preempted or cancelled: end quietly
            n = upstream.next() => n,
        };
        match next {
            Some(Ok(mut chunk)) => {
                let room = (p.end - offset + 1) as usize;
                if chunk.len() > room { chunk.truncate(room); }
                while !chunk.is_empty() {
                    let piece = chunk.split_to(chunk.len().min(PIECE));
                    let wait = p.segment.throttle.lock().unwrap_or_else(|e| e.into_inner())
                        .take(piece.len() as u64, p.dd.now_us());
                    if wait > 0 {
                        tokio::select! {
                            _ = cancel.changed() => break 'outer,
                            _ = tokio::time::sleep(Duration::from_micros(wait)) => {}
                        }
                    }
                    let len = piece.len() as u64;
                    match tokio::time::timeout(stall, tx.send(Ok(piece))).await {
                        Ok(Ok(())) => offset += len,
                        _ => break 'outer,                   // client gone, or stalled for `stall_timeout`
                    }
                    if offset - flushed_from >= FLUSH {
                        if flush(&p, &mut flushed_from, offset) == Progress::OverServed { break 'outer; }
                    }
                }
            }
            Some(Err(_)) | None if offset <= p.end => {      // upstream cut early
                p.dd.stats.record_upstream_error();
                if retries == 0 { let _ = tx.send(Err(io::Error::other("upstream failed"))).await; break 'outer; }
                retries -= 1;
                sleep(backoff(attempt)).await;               // 250 ms, then 1 s
                match p.dd.backends.open(p.kind, &p.file, offset, p.end).await {
                    Ok(r) => upstream = r.bytes_stream(),
                    Err(BackendError::SourceChanged) => { p.dd.grants.fail_source_changed(&p.grant_id, now_ms()); let _ = tx.send(Err(io::Error::other("source changed"))).await; break 'outer; }
                    Err(_) => continue,                      // consumes a retry on the next loop pass
                }
            }
            _ => break,
        }
    }
    flush(&p, &mut flushed_from, offset);                    // final accounting (also on cancel/stall/disconnect)
}
```
